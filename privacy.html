Privacy policy

Last updated: October 22, 2026

Who we are

NOON Store is a personal app store by Muhammad Hamra. Every app is published on GitHub at github.com/mhamad-code.

What this site collects

Nothing. There are no accounts, no forms, no analytics and no advertising cookies. We do not store or sell personal data.

What happens in your browser

  • The pages read a data file from this site and, when needed, ask the public GitHub API for the list of apps. GitHub receives your IP address and browser details as part of that request, under its own privacy statement.
  • Responses are cached in your browser (local storage) for a few minutes to save requests. You can clear them anytime in your browser settings.
  • Icons and screenshots are loaded from GitHub servers.

Downloads

App files are served directly by GitHub from the releases of each repository. GitHub counts downloads and may log them.

Children

The site is not directed at children and does not knowingly collect any data from them.

Changes and contact

We may update this policy and will change the date above. Questions: message the developer at github.com/mhamad-code.
